Aurex: a private AI desktop app that uses your own API keys

Aurex is a local-first AI workspace for your computer. Use OpenAI, Anthropic and other models with your own API keys, chat with your own files, and approve every command and file change the agent makes. Free 3-month beta.

Features

  • Model Fabric: routes tasks to local or cloud models and fails over when a provider hits a billing limit
  • Live cost shown for every chat
  • Agent mode and Chat mode
  • Obsidian vault sync with a visual knowledge graph
  • Email (IMAP) and calendar (CalDAV) integration, contacts sync, task scheduling
  • Terminal Cookbook and secure shell execution
  • Trust Layer: visual diff and approval before destructive actions
  • Context Compactor for long sessions
  • Study tools: flashcards, deep research, PDF and PPTX export

Pricing

Free beta for 3 months. Founder's Lifetime: $99 one-time for the first 100 Founders. Student and Pro subscriptions launch with version 1.0. You pay your AI provider directly for API usage.
